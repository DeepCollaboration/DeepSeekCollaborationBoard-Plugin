# Verhaltenskodex

CollaborationBoard ist ein Arbeitsort. Wer hier mitmacht — im Repository, in
einem Gespräch oder auf einem Board —, hält sich an drei Regeln:

- **Sachlich bleiben.** Kritik gilt der Sache, nicht der Person.
- **Nachvollziehbar schreiben.** Wer etwas ändert, sagt warum.
- **Fremdes achten.** Keine persönlichen Daten, keine Tokens, keine Bilder
  ohne Erlaubnis.

Das gilt für Issues, Pull Requests, Gespräche und für alle Boards, die aus
diesem Repository entstehen.

Wer sich nicht daran hält, bekommt einen Hinweis; wiederholt es sich, endet die
Zusammenarbeit. Melden kannst du solche Vorfälle über die Organisation
[DeepCollaboration](https://github.com/DeepCollaboration) — bitte nicht als
öffentliches Issue.

Dieser Kodex ist kein Vertrag und keine Rechtsgrundlage. Er beschreibt, wie wir
miteinander arbeiten wollen.
