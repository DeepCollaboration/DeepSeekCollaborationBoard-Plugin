## ما هو

يجمع CollaborationBoard المحطات وسير العمل والمشاريع واللوحات في سطح واحد داخل DeepSeek Harness. تعيش كلها في مستودعات Git مستقلة، ولا تحتفظ اللوحة إلا بالمراجع. لا توجد خدمة خاصة، ولا قاعدة بيانات، ولا تسجيل دخول منفصل.

- **المحطة** — خطوة عمل واحدة: ما يدخلها، وما يخرج منها، وكيف تعمل، مع أمثلة وحدود. ملفها الأساسي هو `station.json`.
- **سير العمل** — تركيب من المحطات بترتيب وتفرعات وقواعد. ملفه الأساسي هو `workflow.json`، ويشير إلى المحطات بإصدار بدل نسخها.
- **المشروع** — العمل الفعلي على سير عمل: الاسم والموضع والمسؤولون عن كل خطوة والملفات والنصوص. ملفه الأساسي هو `vorhaben.json`.
- **اللوحة** — مستودع مليء بالمراجع: أي سير عمل ومشاريع ومحطات يستخدمها شخص أو فريق. **اللوحة الرئيسية** العامة هي صفحة البداية، وإلى جانبها لوحات الفرق ولوحات محلية بلا مستودع بعيد.

## المتطلبات

- DeepSeek Harness (DSH)
- Node 24
- Git

## التثبيت

```bash
dsh plugin --profile web add github:DeepCollaboration/DeepSeekCollaborationBoard-Plugin
```

يُثبَّت البرنامج الإضافي في ملف التعريف `web` ويُفعَّل هناك. أعد تشغيل DSH بعد ذلك، فتظهر الصفحة في الشريط الجانبي.

## أول تشغيل

عند أول تشغيل، ينزّل البرنامج اللوحة الرئيسية العامة ويسجّلها، ثم يحمّل المحطات وسير العمل والمشاريع التي تشير إليها. يمكنك القراءة والاستكشاف بلا اسم وبلا رمز. ولإنشاء محطة تحتاج إلى رمز GitHub ومالك، ويُحدَّدان في **الإعدادات → Board → GitHub**. بعد ذلك، أنشئ محطتك الأولى من المكتبة، تحت **المحطات**.
