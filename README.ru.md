## Что это

CollaborationBoard собирает станции, рабочие процессы, проекты и доски на одной поверхности в DeepSeek Harness. Каждая вещь живёт в своём Git-репозитории; доска хранит только ссылки. Здесь нет отдельного сервиса, базы данных и собственного входа в систему.

- **Станция** — один шаг работы: что входит, что выходит, как он выполняется, с примерами и границами. Её якорный файл — `station.json`.
- **Рабочий процесс** — композиция станций с порядком, ветвлениями и правилами. Его якорный файл — `workflow.json`; он ссылается на станции с указанием версии, а не копирует их.
- **Проект** — конкретная работа над процессом: имя, позиция, ответственные на каждом шаге, файлы и транскрипты. Его якорный файл — `vorhaben.json`.
- **Доска** — репозиторий ссылок: какие процессы, проекты и станции использует человек или команда. Публичная **главная доска** — это стартовая страница; рядом есть командные доски и локальные доски без удалённого репозитория.

## Требования

- DeepSeek Harness (DSH)
- Node 24
- Git

## Установка

```bash
dsh plugin --profile web add github:DeepCollaboration/DeepSeekCollaborationBoard-Plugin
```

Плагин устанавливается в профиль `web` и включается там. После этого перезапустите DSH; страница появится в боковой панели.

## Первый запуск

При первом запуске доска сама загружает публичную главную доску, регистрирует её и подтягивает станции, процессы и проекты, на которые она ссылается. Читать и осматриваться можно без имени и без токена. Чтобы создать станцию, нужны токен GitHub и владелец; и то и другое указывается в **Настройки → Board → GitHub**. После этого создайте первую станцию в библиотеке, в разделе **Станции**.
