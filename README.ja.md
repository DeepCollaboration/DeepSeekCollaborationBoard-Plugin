## これは何か

CollaborationBoard は、ステーション、ワークフロー、プロジェクト、ボードを DeepSeek Harness の中で一つのサーフェスにまとめます。それぞれは独立した Git リポジトリにあり、ボードは参照だけを保持します。専用のサービスもデータベースも、独自のログインもありません。

- **ステーション** — 一つの作業ステップ。何を受け取り、何を出力し、どう動くかを、例と限界とともに表します。アンカーファイルは `station.json` です。
- **ワークフロー** — 順序、分岐、ルールを持つステーションの組み合わせ。アンカーファイルは `workflow.json` で、ステーションをコピーせず、バージョン付きで参照します。
- **プロジェクト** — ワークフロー上の具体的な作業。名前、位置、各ステップの担当者、ファイル、トランスクリプトを持ちます。アンカーファイルは `vorhaben.json` です。
- **ボード** — 参照を集めたリポジトリ。誰が、どのワークフロー、プロジェクト、ステーションを使うかを示します。公開の**メインボード**がスタートページで、ほかにチームボードとリモートのないローカルボードがあります。

## 前提

- DeepSeek Harness（DSH）
- Node 24
- Git

## インストール

```bash
dsh plugin --profile web add github:DeepCollaboration/DeepSeekCollaborationBoard-Plugin
```

プラグインは `web` プロファイルにインストールされ、そこで有効になります。その後 DSH を再起動すると、サイドバーにページが現れます。

## 最初の起動

初回起動時に、ボードは公開のメインボードを取得して登録し、それが参照するステーション、ワークフロー、プロジェクトも読み込みます。名前もトークンもなしで閲覧できます。ステーションを作成するには GitHub のトークンとオーナーが必要で、どちらも **設定 → Board → GitHub** で指定します。その後、ライブラリの**ステーション**から最初のステーションを作成できます。
